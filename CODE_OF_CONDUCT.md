# Code of conduct

We want participation in this project to be safe, focused, and respectful.

Be constructive, discuss ideas rather than people, respect privacy, and avoid harassment, discrimination, threats, or unwanted personal attention. Do not publish another person's private information or production customer data. Technical disagreement is welcome when it is specific and evidence-based.

Maintainers may edit or remove harmful content, close interactions that cannot remain productive, and temporarily or permanently restrict participation. Enforcement decisions should consider context, impact, and a person's response to feedback.

Report conduct concerns privately to a maintainer through the repository's available private contact mechanism. Do not use a public issue when doing so would expose a target or reporter.
